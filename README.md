# PassatExpress
Strona internetowa sklepu z passatami, oraz dashboard dla dilerów samochodowych wraz z logowaniem i admin panelem.

# Jak odpalić?
## Linux
```bash
git clone https://github.com/tpmej/passat-express
cd passat-express
bash localhost.bash
```
## Windows
```cmd
git clone https://github.com/tpmej/passat-express
cd passat-express
localhost.bat
```
